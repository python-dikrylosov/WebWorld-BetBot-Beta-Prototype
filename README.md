## 🎯 Концепция <a name="concept"></a>

Цель этого Beta-прототипа — продемонстрировать концепцию и осуществимость системы, объединяющей возможности **модели мира для веба** и **внешнего аналитического ИИ**, для автоматизации процесса анализа спортивных событий (в данном случае, мужского тенниса ATP) и выполнения букмекерских ставок на основе этого анализа.

Система состоит из нескольких ключевых компонентов, работающих в связке:

1.  **Интерпретация веб-окружения.**
2.  **Анализ данных и принятие решений.**
3.  **Выполнение веб-действий.**
4.  **Интеграция и управление.**

## 🔧 Компоненты <a name="components"></a>

- **WebWorld (дообученная модель):**
    - **Роль:** Модель мира, отвечающая за *понимание веб-страниц* и *планирование последовательности действий* на них.
    - **Функции:**
        - Анализ состояния страницы (например, A11y Tree).
        - Генерация веб-действий (`click`, `fill`, `scroll`).
        - Использование специального действия `send_msg_to_user` для *запроса внешней информации* (например, аналитических данных о матче).

- **`qwen-coder` (или другая внешняя модель/инструмент):**
    - **Роль:** Модель *анализа и принятия решений*.
    - **Функции:**
        - Получение *данных из интернета* (статистика тенниса, рейтинги).
        - *Анализ* полученных данных для прогнозирования исхода события.
        - *Принятие решения* о ставке (на кого ставить, какую сумму).

- **Selenium:**
    - **Роль:** Инструмент *физического взаимодействия* с браузером.
    - **Функции:**
        - Открытие и навигация по веб-сайтам букмекерских контор.
        - Выполнение конкретных действий (нажатие кнопок, ввод текста), *указанных* WebWorld.

- **Python-скрипт-агента:**
    - **Роль:** *Центральный управляющий элемент*, связывающий все компоненты в единый рабочий процесс.
    - **Функции:**
        - Управление циклом: захват состояния -> вызов WebWorld -> интерпретация вывода (включая `send_msg_to_user`) -> вызов `qwen-coder` (для анализа) -> возврат данных в WebWorld -> выполнение действий через Selenium.

## 🚀 План Действий <a name="plan"></a>

1.  **Скачивание и подготовка:**
    - Скачать модель WebWorld (например, `WebWorld-8B`) и датасет `WebWorldData`.
2.  **Адаптация данных:**
    - Изучить формат `WebWorldData` (JSONL, разговоры).
    - Перевести текстовую часть `WebWorldData` на **русский язык**, используя `qwen-coder`.
    - Провести ручную проверку качества перевода, особенно структуры A11y Tree и синтаксиса действий.
    - Подготовить **собственные данные**, описывающие сценарии взаимодействия с русскоязычными сайтами и интеграции с внешней моделью анализа (используя `send_msg_to_user`).
    - Объединить переведённый `WebWorldData` и собственные данные.
3.  **Fine-tuning:**
    - Дообучить выбранную модель WebWorld на объединённом русскоязычном датасете.
4.  **Разработка интеграционного агента:**
    - Создать Python-скрипт, реализующий логику агента.
    - Интегрировать вызовы дообученной модели WebWorld.
    - Интегрировать вызовы `qwen-coder` для анализа теннисных матчей.
    - Интегрировать Selenium для выполнения веб-действий.
    - Реализовать логику обработки `send_msg_to_user` и возврата результатов анализа в контекст WebWorld.

## ✅ Возможности <a name="capabilities"></a>

- **Автоматизированная навигация:** Возможность перемещаться по веб-сайтам букмекерских контор.
- **Интерпретация данных:** Чтение и понимание информации на страницах (коэффициенты, события).
- **Интеграция аналитики:** Возможность вызова внешних моделей для анализа данных.
- **Выполнение цепочек действий:** Последовательное выполнение действий (например, найти матч -> выбрать ставку -> ввести сумму -> подтвердить).
- **Адаптация к языку:** Возможность работы с русскоязычными интерфейсами благодаря дообучению.

## ⚠️ Ограничения <a name="limitations"></a>

- **Точность прогнозов:** Успех всей системы **крайне зависим** от *способности внешней модели анализа* (например, `qwen-coder`) давать *точные* прогнозы. Современные ИИ не идеальны в строгом вероятностном анализе.
- **Надёжность WebWorld:** Модель может ошибаться в понимании сложных или динамических веб-страниц.
- **Блокировки сервисов:** Букмекерские конторы активно борются с ботами, что может привести к ограничениям (limiting) или блокировкам (gubbing) аккаунтов.
- **Юридические аспекты:** Использование автоматизации может нарушать правила платформ или законы конкретных юрисдикций.
- **Сложность реализации:** Интеграция нескольких сложных систем требует значительных технических усилий и тонкой настройки.
